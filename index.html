    구글 드라이브 연동 설정

    구글 스프레드시트 실시간 동기화 설정 방법 (약 1분 소요):
    1. 연동할 Google 스프레드시트를 열고 주소의 /d/와 /edit 사이에 있는 스프레드시트 ID를 복사합니다.
    2. 상단 메뉴 [확장 프로그램] -> [Apps Script]를 클릭합니다.
    3. 아래 [배포용 스크립트 코드 복사] 버튼으로 코드를 붙여넣고, SPREADSHEET_ID의 빈 따옴표 안에 복사한 시트 ID를 입력한 뒤 저장합니다.
    4. 기존 웹 앱은 [배포] → [배포 관리] → [수정] → [새 버전]으로 업데이트하면 같은 URL을 사용할 수 있습니다. 새로 연결할 때는 [새 배포] → [웹 앱]을 선택합니다.
    5. 설정: 실행자 [나], 액세스 권한 [모든 사용자(Anyone)] 필수 선택 후 [배포] 클릭
    6. 생성된 웹 앱 URL을 아래 입력창에 넣고 [연결 테스트 & 동기화]를 누르면 끝!

    이미지 동기화에는 아래 v1.3.2 스크립트가 필요합니다. 첨부 이미지는 웹 앱의 기존 액세스 범위로 공유됩니다.
